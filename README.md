Text Correction & Scraper Tool 📝

A Python script that extracts text from either a Word document (.docx) or a web page, corrects its text (spelling/grammar) using TextBlob, and saves the polished result into a new Word document.
🚀 Features

    Word Document Reader: Extracts paragraphs from local .docx files using python-docx.

    Web Scraping: Fetches and extracts clean text (paragraphs and headers) from any URL using requests and BeautifulSoup.

    Text Correction: Automatically analyzes and corrects spelling mistakes using TextBlob.

    Output Generation: Saves the corrected text directly into a new Word document.
